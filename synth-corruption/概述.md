# Synth Corruption — 项目概述

## 简介

**Synth Corruption** 是一个赛博朋克风格的双摇杆生存射击游戏（类似 Vampire Survivors 玩法）。纯 HTML5 Canvas + 原生 JavaScript 构建，无任何第三方框架依赖。

## 项目结构

```
synth-corruption/
├── index.html          # 入口，双 Canvas（缓冲层 + 显示层）
├── css/
│   └── style.css       # 像素字体 + CRT 背景布局
├── js/
│   ├── config.js       # 全局常量（网格尺寸、颜色、工具函数）
│   ├── text.js         # 像素文字渲染（支持阴影/自适应字号）
│   ├── state.js        # 状态机（Splash → Playing → Paused → GameOver）
│   ├── input.js        # 键盘 + 鼠标输入管理
│   ├── audio.js        # Web Audio API 合成音效（射击/闪现音）
│   ├── player.js       # 玩家移动、瞄准、射击、闪现冲刺、拖尾残影
│   ├── enemies.js      # 4 种敌人 + 敌弹逻辑
│   ├── cores.js        # Core（核心）生成、腐化传播、刷怪
│   ├── effects.js      # 粒子系统 + CRT 后处理特效
│   ├── game.js         # 主游戏循环、碰撞检测、波次触发
│   ├── render.js       # 所有渲染（网格、HUD、实体、覆盖层）
│   └── main.js         # requestAnimationFrame 启动入口
└── fonts/
    └── PressStart2P-Regular.ttf
```

全部逻辑由 **纯 JavaScript** 实现（约 1500 行），无需 C、Python、WebAssembly 或任何后端服务。

## 核心机制

| 要素 | 说明 |
|------|------|
| **玩家** | WASD 移动，鼠标瞄准，左键射击，空格/右键闪现（dash） |
| **敌人** | Chaser（追兵）、Fast（高速）、Tank（3HP）、Shooter（远程射击） |
| **Core** | 地图上的六边形核心，持续散布红色腐化区域 + 刷怪，摧毁后腐化消失 |
| **Corruption** | 红色网格区域，玩家踩上去减速，核心向外扩散 |
| **波次** | 分数驱动：450 分提示打 Core → 950 分第一个 Core → 2100 分 Wave 2…… |
| **CRT 特效** | 扫描线、画面抖动、glitch 偏移、RGB 分离、像素噪点、暗角，强度随紧张度动态变化 |

## 视觉风格

- 深黑/墨绿底色（`#040509`），搭配青绿（`#48ffce`）、品红（`#f952ff`）、霓虹红
- 所有实体用**线框多边形 + glow 发光阴影**绘制
- 玩家带运动残影拖尾
- **CRT 模拟后处理**：曲面扭曲、RGB 分离、扫描线、噪点、暗角

## 技术实现

| 层面 | 技术 |
|------|------|
| 渲染 | Canvas 2D API |
| 音效 | Web Audio API（OscillatorNode 合成，零音频文件） |
| 存档 | localStorage |
| 性能 | 双缓冲渲染（离屏 buffer → 后处理 → 显示）；动态降质（帧率低时自动减少粒子/扫描线） |
| 架构 | 模块化 IIFE + `window.SC` 命名空间；状态机驱动 |

## 技术亮点

- **双缓冲**：`canvas#g`（离屏缓冲）→ 后处理 → `canvas#c`（显示），避免闪烁
- **动态降质**：检测到帧率低（`slowFrames > 20`）自动减少粒子和扫描线
- **纯合成音效**：零音频文件，全部用 Web Audio API 的 OscillatorNode 合成
- **状态机架构**：清晰的 4 状态切换，各模块通过 `window.SC` 命名空间解耦
- **防御性编程**：所有集合有上限（子弹 ≤ 96、敌人 ≤ 38、粒子 ≤ 140）
