# TypeScript 任务书

目标：给 Python 智能体做一个网页任务面板。

按顺序完成，每次只做一个任务。前 5 个练习放在 `ts/`，页面项目放在 `task/agent-panel/`。

| 完成 | 任务 | 学什么 | 完成标准 |
| --- | --- | --- | --- |
| [ ] | 1. 消息列表：定义消息，添加消息，筛选用户消息 | 对象类型、字面量联合、类型推断 | 角色只能是 `user/assistant/system`，拼错会报类型错误 |
| [ ] | 2. 任务状态：定义等待、运行、成功、失败 | 联合类型、类型收窄、`never` | 成功必须有结果，失败必须有错误；新增状态能发现遗漏分支 |
| [ ] | 3. 读取 JSON：检查模拟后端数据 | `unknown`、运行时校验 | 合法数据能读取，缺字段或字段类型错误能拒绝 |
| [ ] | 4. 通用结果：定义 `Result<T>`，用于消息和任务 | 泛型 | 同一结果结构能保留不同数据类型，不用 `any` |
| [ ] | 5. 智能体配置：定义配置和配置更新参数 | `keyof`、`Partial`、`satisfies` | 配置键拼错或值类型错误会报错；更新类型从配置类型派生 |
| [ ] | 6. 网页面板：输入问题，提交，显示状态和模拟回复 | DOM、事件、`async/await` | 浏览器能完成一次模拟任务，展示成功和失败 |
| [ ] | 7. 接入 Python：把模拟请求换成真实请求 | `fetch`、接口契约、数据校验 | 网页能调用智能体，并处理请求失败和错误数据 |

学习规则：

- 开启 TypeScript 的 `strict` 检查。
- 每个任务故意写一次错误，观察编译器能否发现。
- `as` 不会转换或校验数据；外部数据需要运行时检查。
- 做完模拟面板，再学 React，重做同一页面。
